# 🕌 StepToDeen - Aapka Digital Islami Saathi

**StepToDeen** aik mukammal tor par **muft, open source** aur **baghair ishtiharat (ads)** ke islamic application hai. Ye aapke deen ki rehnumai ke liye aik taqatwar digital saathi hai.

[![Live Demo Dekhein](https://img.shields.io/badge/Live_Demo-Yahan_Click_Karein-green?style=for-the-badge&logo=cloudflare)](https://steptodeen.hubproapk.workers.dev/)

---

## ✨ koch feature (Features)

| Zumer | Tafseel |
| :--- | :--- |
| 📖 **Quran Majeed** | Mukammal 114 Suratein (Makki aur Madani), **Urdu tarjuma** ke saath, Arabic audio tilawat bhi mojood hai |
| 🤲 **Masnoon Duaein** | Rozmarra ke azkar o kalmaat, mukhtalif mauqon ki duaein |
| 🕌 **Namaz ka Tariqa** | Mukammal tarjuma aur tariqa kar ke saath namaz seekhein |
| 📿 **Tasbeeh Counter** | Click kar ke aasani se tasbeeh parhne ka counter |
| 🧭 **Qibla Rukh Simt** | Durust qibla simt maloom karne ke liye compass |
| ⏰ **Namaz ke Auqat** | **Khaas feature:** Aapki location ke **qareebi masjid** ke auqat. Aimah karam **Firebase** ke zariye apni masjid ke auqat khud life time update kar sakte hain. |
| 👤 **User Login** | Zati tajarbay ke liye login sahulat |
| ⚡ **Mazban (Hosting)** | Cloudflare Workers par live, tez raftaar aur qabil-e-bharosa |
| 📗 **kitub-e-hadith** | bukhari Muslim **aur 9 mazeed** + urdu tarjuma |

## 🛠️ Technology (Built With)

Ye app jadeed web technologies ke saath bani hai:

- **TypeScript** (96.7%) - mazboot aur mehfooz code
- **Vite** - tez raftaar build tool
- **Cloudflare Workers** - backend aur hosting
- **Firebase** - database aur user authentication
- **Service Workers** - offline support aur sync
